# Запуск в Visual Studio

Откройте ServiceDesk.sln в Visual Studio 2022 с .NET 8. Восстановите пакеты NuGet и выполните «Сборка → Перестроить решение».

Назначьте Verification запускаемым проектом. В списке профилей выберите ПР 4, 5, 6, 7 или 8 и нажмите Ctrl+F5. Программа сама находит папку решения, запускает API и выполняет проверки. В консоли показан фактический вывод выбранной работы. Все зависимые проекты собираются автоматически в выбранной конфигурации Debug или Release. Общий прогон содержит 13 сценариев; файлы результатов сохраняются в RunResults.

| Работа | Что открыть и снять в Windows |
| --- | --- |
| ПР 4 | Code/ServiceDeskApi/Program.cs и результат проверки совместимости API v1/v2 |
| ПР 5 | Code/Operations/Program.cs и вывод миграции Expand/Contract |
| ПР 6 | Code/CalsExchange/Program.cs, обмен JSON/XML, конфликт редакций и состав изделия |
| ПР 7 | Code/Operations/Program.cs и протокол SAT с кодами HTTP |
| ПР 8 | Обновление, отказ при неверном SHA-256, доставка после восстановления связи и защита DPAPI |

Снимки делайте Win+Shift+S. В кадр должны входить Visual Studio, название проекта и читаемый вывод программы. Текстовый протокол и HTML-журнал не заменяют снимок запуска. DPAPI проверяется на Windows.

Отдельный API можно запустить через профиль проекта ServiceDeskApi: назначьте его запускаемым, нажмите Ctrl+F5. Не меняйте порты во время автоматического прогона Verification.
