# Проверка МДК 03.01 — 12.11.2026

Сверка выполнена с учебным сборником и присланными отчётами Мельника. Чужой вариант, текст, код и измерения не копировались. Дополнительный материал примера отделён от обязательного задания.

| Работа | Проверено и изменено | Сравнение и границы |
|---|---|---|
| ПР1 | Матрица подсистем и нормативной базы есть. Уточнены исторический ГОСТ 34.601-90 и действующий ГОСТ Р 59793-2021. | У Мельника больше автоматизации; она не обязательна для ПР1 в сборнике. |
| ПР2 | Есть L1–L3, четыре приоритета, реакция, восстановление и эскалация. | У Мельника дополнительно утилита SLA; у нас регламент и схема. |
| ПР3 | Есть модель критического инцидента, хронология, RCA, меры и расчёты MTBF/MTTR/доступности. | У Мельника подробнее аудит процесса; у нас действия и критерий закрытия конкретизированы. |
| ПР4 | Есть Program.cs API, версии URL v1/v2, старый клиент и семь проверок; добавлены снимки Windows. | Требуемая функциональность присутствует; данные API учебные, в памяти процесса. |
| ПР5 | Есть Expand/Contract, сохранение данных в SQLite, меры релиза и структура эксплуатационных документов; снимок Windows. | У Мельника больше эксплуатационных примеров; у нас исполняемая миграция на SQLite. |
| ПР6 | Есть SSOT, электронный состав, JSON/XML, контроль редакции и пять проверок; снимок Windows. | У Мельника дополнительно автооткат; перечень задания требует концепцию CALS и обмен, это выполнено. |
| ПР7 | Есть Go-Live, обучение, FAT/SAT, критерии приёмки и стендовый SAT 4/4; снимок Windows. | Стендовый протокол не подменяет акт заказчика, это явно оговорено. |
| ПР8 | Есть SemVer/SHA-256, офлайн-буфер SQLite/EF Core/Polly, BCrypt/RBAC/X.509/DPAPI, backup и SAT; снимки Windows. | У Мельника портфолио ПК19–25 шире. Все модули из итогового перечня задания представлены. SHA-256 не заменяет подпись манифеста. |

## Основания проверки

- Задания преподавателя МДК 03.01 ПР1–8, МДК 03.02 ПР1–8 и эссе, МДК 02.02 ПР1–9.
- Материалы Мельника, предоставленные пользователем (15 документов по 03.01, 8 по 03.02, 9 по 02.02).
- Исходники, документы, исходные журналы и снимки Windows пользователя.
- Росстандарт: https://protect.gost.ru/gost/details/338f52dc-7165-4d28-8d35-5258fc7e8740
- C4: https://c4model.com/diagrams/notation
- ISO: https://www.iso.org/standard/78176.html

## Пределы заключения

Проверка документов и кода не гарантирует оценку преподавателя. Новое выполнение всех программ на локальном Windows-компьютере автора проверки не заявляется. Снимки пользователя и исходные журналы сохранены с происхождением; результаты старого прогона не называются новым прогоном.
