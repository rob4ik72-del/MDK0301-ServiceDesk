# МДК 03.01 — Служба заявок

Учебная система регистрации заявок и портфолио по ПР 1–8.
Репозиторий: https://github.com/rob4ik72-del/MDK0301-ServiceDesk

## Запуск

Нужен .NET 8 SDK. Из корня на Windows запустите `Verify.cmd`.
Команды для любого поддерживаемого окружения:

```sh
dotnet build ServiceDesk.sln -c Release
dotnet run --project Code/Verification -c Release --no-build -- . RunResults
```

Проверка сама запускает API на свободном локальном порту, выполняет 12 сценариев,
проверяет коды завершения и вывод, затем останавливает сервер.
В RunResults появятся журналы, HTML с фактическим выводом, SAT.md и ZIP с SHA-256.
DPAPI проверяется только на Windows. Тест X.509 использует временный учебный CA;
в системное хранилище сертификаты не устанавливаются.

| Работа | Программа или результат |
|---|---|
| ПР 1 | Матрица стандартов в отчёте |
| ПР 2 | Регламент L1–L3 и SLA в отчёте |
| ПР 3 | Post-Mortem и расчёты в отчёте, входной пример в Code/sample-data |
| ПР 4 | Code/ServiceDeskApi и Code/ApiCompatibilityTests; Run_PR04_API.cmd |
| ПР 5 | Code/Operations, команда migration; SQL в Code/sample-data |
| ПР 6 | Модель данных и примеры JSON/XML в отчёте |
| ПР 7 | Code/Operations, команда sat; оболочка Code/Scripts/sat-report.ps1 |
| ПР 8 | Code/Updater, Code/OfflineBuffer, Code/SecurityDemo, Code/Operations |

ПР 4 вручную: запустите `Run_PR04_API.cmd` и откройте http://127.0.0.1:5000/.
Во втором окне выполните `dotnet run --project Code/ApiCompatibilityTests`,
после чего обновите страницу.

## Границы учебной системы

Данные API находятся в памяти процесса. Ключ повторной доставки действует до
перезапуска сервера. Миграция проверяется на отдельной базе SQLite.
SHA-256 проверяет целостность пакета относительно доверенного манифеста;
подлинность самого манифеста должна обеспечиваться отдельно. Обновлятор
не запускает пакет и не предназначен для параллельной установки.
Модуль RBAC проверяет локальную матрицу прав, а не авторизацию на HTTP API.
В SAT зафиксирован стендовый прогон; акт заказчика не составлялся.

Отчёты: Reports. Схемы и снимки: Images. Журналы текущего прогона: Evidence.
